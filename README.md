# Random String Generator 

A simple and interactive **Random String Generator** web application built using **React.js**.  
This application allows users to generate random strings based on the selected length and character options.

##  Features

-  Generate random strings instantly
-  Customize string length
- Supports uppercase and lowercase letters
- Includes numbers
- Includes special characters
- Easy to copy generated strings
- Fast and responsive UI

## Technologies Used

- React.js
- JavaScript 
- HTML
- CSS
- Vite
